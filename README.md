# 👨‍🏫 Practicando con Interfaces

## 📋 Enunciado

Un sistema existente necesita incorporar funcionalidad que permita enviar mensajes a través de correo electrónico, SMS y WhatsApp a sus usuarios.

## 🛠️ Resolución

Se emplearán interfaces de C#, para definir un contrato sobre las propiedades y métodos que deberán implementar las clases encargadas de los distintos medios de mensajería.
